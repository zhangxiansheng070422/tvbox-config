# 订阅地址清单 —— 定时任务每 6 小时读一次这个文件
#
# 一行一个地址，# 开头是注释，空行忽略。
# 支持两种写法，可以混着写：
#
#   A. 直接给一个配置地址（返回 JSON，里面有 sites / lives / parses / spider）
#   B. 给一个「地址清单」（纯文本，里面一行一个配置地址）—— 会自动展开一层，
#      清单套清单最多两层，一个清单最多展开 20 条。
#
# 抓回来之后会做的事：
#   校验是合法配置 → 按 key / api / name 去重 → 并进 config.json（只增不删）
#   → 顺带探测每个站点接口活没活着，写进 vod-status.md
#
# 直播列表默认不会被远端覆盖（你那 110 个台是自己调好的）。
# 点播站点则是有多少并多少。
#
# 单条地址失败不影响其他条；全部失败时配置文件保持原样，不会被改坏。
#
